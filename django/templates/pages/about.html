About StarWolf

StarWolf is a personal stargazing trip planner built by Seth and Travis Wolverton. It pulls live weather and atmospheric data, combines it with moon phase and light pollution information, and scores each site/night combination so you can find the best window for your next observing session.

StarWolf is a non-commercial, personal project. It is not affiliated with any of the data providers listed below. Forecasts are for planning purposes only — conditions can change. This is not a professional meteorological service.

Data Sources

☁️ Weather Forecasts — Open-Meteo

Provider: Open-Meteo

Open-Meteo is a free, open-source weather API that aggregates forecasts from national weather services worldwide. StarWolf uses it for cloud cover, precipitation probability, humidity, visibility, and atmospheric stability (lifted index).

  • License: CC BY 4.0 — attribution required
  • Update frequency: Hourly
  • Coverage: Global
  • Terms: open-meteo.com/en/terms
🔭 Astronomical Seeing & Transparency — 7timer!

Provider: 7timer! by Ye Quanzhi, Tongji University

7timer! is a free astronomical weather service purpose-built for observers. StarWolf uses its ASTRO product for seeing (atmospheric steadiness) and sky transparency. Both are rated on a 1–8 scale where 1 is best. Coverage is limited to approximately 3 days ahead — nights beyond that show — for these fields.

  • License: Free academic service; attribution requested
  • Update frequency: Every 6 hours
  • Coverage: Global, ~3-day horizon
🌑 Dark Sky Site Catalog — IDA / DarkSky International

Provider: International Dark-Sky Association / DarkSky.org

The site catalog is seeded from the IDA's publicly published list of designated International Dark Sky Places. Coordinates were sourced via the OpenStreetMap Overpass API, where IDA-designated locations are tagged by the OSM community.

  • IDA designation data: Publicly published, non-commercial use
  • Coordinate data: OpenStreetMap contributors, ODbL
  • © OpenStreetMap contributors
📍 Geocoding — Nominatim / OpenStreetMap

Provider: Nominatim (OpenStreetMap)

Nominatim is used to convert addresses and place names to coordinates when you set your location or add a site by address. It is operated by the OpenStreetMap Foundation and is free for low-volume, non-commercial use.

  • License: ODbL — © OpenStreetMap contributors
  • Usage policy: nominatim.org
  • Rate: Max 1 request/second per Nominatim's usage policy. Used for address lookup (location page) and reverse-geocoding the site catalog.
💡 Light Pollution Data — World Atlas of Artificial Night Sky Brightness

Provider: Falchi et al. (2016), GFZ German Research Centre for Geosciences

StarWolf uses this dataset to look up Bortle class estimates when adding new dark-sky sites. The dataset maps artificial sky brightness worldwide at ~1 km resolution.

  • Full citation: Fabio Falchi, Pierantonio Cinzano, Dan Duriscoe, Christopher C.M. Kyba, Christopher D. Elvidge, Kimberly Baugh, Boris A. Portnov, Nataliya A. Rybnikova, Riccardo Motta (2016): The new world atlas of artificial night sky brightness. V. 1.1. GFZ Data Services. doi.org/10.5880/GFZ.1.4.2016.001
  • License: CC BY 4.0 — attribution required
🔍 Address Autocomplete — Photon / Komoot

Provider: Photon by Komoot

Photon powers the address autocomplete on the Set Location page. It is a free, open-source geocoder built on OpenStreetMap data, operated by Komoot with no API key required.

  • Data: © OpenStreetMap contributors, ODbL
  • Usage: Free for non-commercial use
📖 Site Descriptions — Wikipedia

Provider: Wikipedia / Wikimedia Foundation

Site descriptions are generated by passing Wikipedia article summaries (fetched via the free Wikipedia REST API) to a local AI model, which rewrites them as concise, stargazer-focused notes. No Wikipedia content is stored verbatim.

  • License: CC BY-SA 4.0
  • API: Wikipedia REST API — free, no key required
🌙 Moon & Astronomical Calculations — astral

Library: astral by Simon Kennedy

Astral provides moon phase, illumination, and rise/set calculations used in StarWolf's moon scoring factor.

  • License: Apache 2.0
🪐 Planetary & Sky Ephemeris — skyfield + DE421

Library: skyfield by Brandon Rhodes

Ephemeris: DE421, NASA Jet Propulsion Laboratory

skyfield computes precise positions of the Sun, Moon, and planets using the JPL DE421 planetary ephemeris. StarWolf uses it to calculate rise/set times, peak altitude, peak azimuth (compass direction), and visibility windows for all sky objects on the Tonight's Sky and What's Up? pages.

  • skyfield license: MIT
  • DE421 ephemeris: Public domain, NASA/JPL — baked into the Docker image at build time
🌌 Deep Sky Object Catalog — Messier Catalog

StarWolf bundles a catalog of all 110 Messier objects (galaxies, nebulae, star clusters) with coordinates, magnitudes, and common names. Object visibility is computed against each site's limiting magnitude derived from its Bortle class.

  • Data: Compiled from public-domain astronomical literature; no license restrictions
  • Coverage: All 110 Messier objects (M1–M110)
🛸 ISS Pass Predictions — Celestrak

Provider: Celestrak (Dr. T.S. Kelso)

ISS pass times are computed using Two-Line Element (TLE) orbital data fetched from Celestrak and processed by skyfield. TLE data is cached for 6 hours.

  • TLE source: Celestrak GP Data — ISS (ZARYA, NORAD 25544)
  • License: Free for non-commercial use; attribution appreciated
🖼️ Site Images — Wikimedia Commons

Provider: Wikimedia Commons / Wikimedia Foundation

Site thumbnail images are fetched via the Wikipedia PageImages API, which returns representative images from Wikimedia Commons. Images are loaded directly from Wikimedia CDN — StarWolf does not host or cache them.

  • API: Wikipedia PageImages API — free, no key required
  • License: Varies per image; most are CC BY-SA. Credits are displayed with each image.
📡 Visitor Location — ipwho.is

Provider: ipwho.is

When you first visit StarWolf without a saved location, your approximate location is estimated from your IP address using ipwho.is. This is used only to pre-populate the location field — it is not stored, logged, or used for any other purpose. IP addresses are never sent to ipwho.is directly; only the server's outbound request is made.

  • License: Free tier, non-commercial use
  • Data stored: None — IP geolocation is used for the initial location estimate only
🤖 AI Forecast Summaries — Ollama

Runtime: Ollama (MIT License)

When enabled, StarWolf generates plain-language forecast summaries using a large language model running locally on the host machine via Ollama. No data is sent to any external AI service.

  • Default model: Llama 3.1 8B by Meta (Meta Llama 3 Community License)
  • Data privacy: All AI inference is local; your forecast data never leaves your machine
  • This feature is optional and can be disabled in Admin → App Settings

Architecture

StarWolf is a self-hosted Python web app built for a single-server deployment. Here's what's running under the hood:

Frontend

Django 5 + HTMX + Alpine.js
Server-rendered HTML with HTMX for partial page updates and Alpine.js for lightweight client-side interactivity (tooltips, show/hide, date pickers).

📡 API Guide →

Data Layer

PostgreSQL 16
Stores the site catalog, site details (Wikipedia summaries, images, narratives), app settings, user preferences, and visitor log.

Redis 7
Forecast cache with TTL-based expiry (1 hour for Open-Meteo, 3 hours for 7timer, 1 hour for sky object calculations, 6 hours for ISS TLE data).

Scoring Engine

scorer.py
Computes a 0–100 composite score per site/night by averaging nighttime hours across five weighted factors: cloud cover, high cloud, moon phase, atmospheric stability (lifted index), and humidity. A separate naked eye score applies different weights and a Bortle class modifier. Weights are live-editable in the Admin panel.

forecast.py
Fetches and merges Open-Meteo (hourly) and 7timer! (6-hourly ASTRO) forecasts per site. All network calls are Redis-cached.

sky_objects.py
Computes what's visible in the sky for any lat/lon and date using skyfield and the JPL DE421 ephemeris. Covers planets, Moon, Messier DSOs, meteor showers, and ISS passes. Results are cached 1 hour per site/date/equipment combination.

bortle_lookup.py
Reads a single pixel from the 2.9 GB Falchi et al. 2016 GeoTIFF using rasterio — lazy read, no full file load, returns in milliseconds.

Infrastructure

Docker Compose
Three services: django (gunicorn, port 8080), db (Postgres), redis. The World Atlas GeoTIFF and JPL DE421 ephemeris are baked into the image at build time.

Ollama (host, optional)
Local LLM inference for AI site narratives and forecast summaries. Runs outside Docker, reachable via host.docker.internal:11434. No data leaves the machine.
